# 示例合同履约资料清单

> 通用示例，用于演示“其他资料”分类与关键词检索。实际项目应按合同约定、企业流程和适用要求调整；本清单本身不构成法律意见。

## 签约前

- 交易背景、采购或项目需求说明
- 双方主体名称、联系人及授权签署材料
- 报价单、技术规格、服务范围和工作说明书
- 已确认的合同版本、附件目录和版本日期
- 涉及分包、第三方服务或数据处理的事项说明

## 履约中

- 交付计划、阶段里程碑和双方负责人
- 发货、部署、服务工单或交付记录
- 验收标准、测试记录、验收意见和整改闭环
- 变更申请、审批记录及双方确认文件
- 会议纪要、通知送达记录和问题跟踪表

## 付款与结项

- 发票信息、付款申请和合同约定的支持性单据
- 已完成的交付与验收记录
- 质保、维护、培训或持续服务的联系人及安排
- 账号、设备、资料和数据的移交、返还或删除记录
- 未结事项、争议事项和后续责任人清单

## 资料核对提示

- 文件名称应能识别项目、合同版本和形成日期。
- 重要沟通应保留发送方、接收方、时间和附件版本。
- 资料清单用于帮助项目团队归档，不代表每项资料在所有交易中都必须提供。
